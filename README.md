# PROJETO-MARIO-KART
Projeto desenvolvido no bootcamp da DIO: um jogo de batalha por turnos no terminal com Node.js, onde dois jogadores escolhem personagens com atributos próprios, coletam itens e enfrentam terrenos aleatórios (reta, curva e luta). A partida mistura estratégia e sorte em rounds rápidos até restar apenas um vencedor. Ideal para treinar lógica e async.!
