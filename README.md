Projeto desenvolvido no bootcamp da DIO, inspirado no universo do Mario. Aqui, dois jogadores se enfrentam em partidas rápidas e divertidas, escolhendo personagens, usando itens e lidando com desafios aleatórios até que só um vença.

---

## Sobre o projeto

Este jogo foi criado para praticar programação de um jeito mais leve e criativo. A ideia é transformar o terminal em uma arena com clima de competição, estratégia e surpresa a cada rodada.

## O que acontece no jogo

* Dois jogadores escolhem personagens
* Cada personagem tem pontos fortes diferentes
* Durante a partida, aparecem itens que podem ajudar (ou atrapalhar)
* O terreno muda a cada turno e influencia o resultado
* Vence quem conseguir zerar a vida do adversário primeiro

---

## Como jogar

1. Escolha os personagens dos dois jogadores
2. Em cada rodada, decida entre atacar, usar item ou checar inventário
3. Acompanhe os resultados e adapte sua estratégia
4. Continue até um dos jogadores ficar com 0 de vida

---

## Como executar

1. Tenha o Node.js instalado (versão 18 ou superior)
2. No terminal (na pasta raiz), rode:

```bash
node .\projeto-mario\index.js
```
